# 跨领域 RSI 基础方法

本文件收录**不属于任何特定应用领域**的通用 RSI 方法（自我改进算法、技能库、
Agent 架构搜索、自我博弈训练、进化方法等）。此前把它们分散计入九个应用领域，
导致「专业知识工作」等领域出现大量无领域依据的条目；现统一独立成册，
**不计入任何应用领域的高水平论文数**。

判断依据与九个领域完全一致：出版层级门槛 + 明确的自我改进机制 + 严格 L1–L7 分级。
